MediaDeck 展开动画

前景卡固定 · 后面的卡铺开 · 多种节奏/层级方案对比。点各卡片下方按钮切换。

A · Front Hold

前景不动；后卡从身下依次滑出。位移时长 > 间隔，层叠波浪；运动中 zIndex 抬到前景之下。

  • ease: cubic-bezier(.22,1,.36,1)（减速落位）
  • stagger 120ms / move 480ms
  • 运动中 z=98，落位后 z=94+

B · Cascade Wave

更连贯：整组几乎同时起步，错峰很小，像流水一样铺开；用更长的减速曲线。

  • ease: cubic-bezier(.16,1,.3,1)
  • stagger 90ms / move 620ms
  • 落位时轻微 scale 1→0.98→1

C · Soft Peel

后卡先「抬起」一点（scale/阴影）再飞出，避免生硬平移；前景带极轻压下。

  • 两段：lift 120ms → travel 420ms
  • 阴影在运动中加深

D · Springs

CSS spring 近似：轻微 overshoot，更「牌桌」手感；间隔拉开，层次更清楚。

  • ease: cubic-bezier(.34,1.4,.64,1)
  • stagger 150ms / move 560ms

建议：真机可优先试 A 或 B；若要更「发牌」感用 C/D。
