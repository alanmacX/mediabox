# 实况窗申请 — UX 设计图制作清单（jpg）

> 对应 AGC 申请页「UX 设计图（jpg 格式）」。所有数字来自华为官方《实况窗设计规范》
> 与《实况窗设计指南》（LiveView 模板细则）。

## 一、必须覆盖的状态 × 展示位矩阵

每个状态出一行图，最终合并为一张 jpg（或按 AGC 上传位数量拆分）：

| 状态 | 状态栏胶囊态 | 卡片态（通知中心） | 锁屏态 |
| --- | --- | --- | --- |
| ① 任务开始 | ✅ 文本胶囊「处理中」 | ✅ 进度模板 0% | ✅ |
| ② 处理中 | ✅ 进度胶囊 x/y | ✅ 进度模板 45% | ✅ |
| ③ 已完成 | ✅ 「完成」 | ✅ 100% 已完成 | ✅（可选） |
| ④ 失败 / 取消 | —（立即结束，无需设计） | — | — |

- 设计图建议直接在系统模板上做标注（胶囊 + 卡片 + 锁屏各一框），标明文案、图标、点击区域。
- 如已用白名单调试设备真机联调，附真机截图最稳妥；申请阶段 UX 稿即可。

## 二、胶囊态硬性规格

- 组成：图标 + 主文本 + 副文本（白色 #FFFFFF，不支持定制文字颜色），右侧圆形辅助图标槽位可选。
- 主文本 **1–3 个中文字**（如「处理中」），副文本 **1–6 个中文字**（如「转码 45%」）；超长由系统渐隐，副文本可跑马灯（仅右侧、跑两遍）。
- 三种类型按状态选用：`CAPSULE_TYPE_TEXT`（开始/完成）、`CAPSULE_TYPE_PROGRESS`（处理中，progress/max 显示 x/y）。
- 图标：系统裁切成同心圆，矢量图预留裁切安全边距；PixelMap ≤ 30KB（API 24 阶段），string 资源名 ≤ 255。
- 胶囊底色如自定义：#ARGB（9 位），避免 #FF000000 / #FFFFFFFF / #FFF1F3F5。

## 三、卡片态硬性规格（LAYOUT_TYPE_PROGRESS 进度模板）

- 结构：固定区（左应用图标 + 主/副文本，必选）+ 辅助区（44×44vp，可选）+ 扩展区（可选）。
- 文本上限（无辅助区）：主文本 ≤16 中文字、副文本 ≤19 中文字；有辅助区 13 / 15。超 1 行 "…" 截断，不支持跑马灯、不支持换行。
- 进度模板节点图标：**2–5 个**（方案取 3 个：解析 → 处理 → 完成）；圆形底板用 svg 图标，自定义底板用 png。
- 进度条颜色 #ARGB（9 位），默认高亮 #FF317AF7、轨道深浅色默认 #19000000 / #19FFFFFF；可用应用品牌色替代但需全界面统一。
- 强调色全界面统一，深浅色模式均需可读（设计图出深色、浅色两版）。

## 四、锁屏态

- 常规：固定区 + 辅助区（36×36vp），主文本 ≤10 中文字、辅助文本 ≤12 中文字（无辅助区时）。
- 沉浸态（点卡片展开）：需提供 `liveViewLockScreenPicture`，**约 1000×1000 图片，不支持 GIF**，放 rawfile，文件名 ≤256 字符。
- 锁屏定制图标 36×36vp。

## 五、素材与文案禁令（自检）

- [ ] 无营销、广告、优惠券、活动预热类文案
- [ ] 无用户隐私信息（不展示原始文件路径等敏感内容，文件名展示做脱敏可接受）
- [ ] 不对同一任务重复叠加普通通知（实况窗替代普通进度通知）
- [ ] 每个状态都有明确结束事件；单窗 ≤8 小时（本场景单任务典型 <30 分钟）
- [ ] 仅用户主动操作触发创建，无静默自动创建
- [ ] 深浅色两版均已核对可读性
- [ ] 所有图片 PixelMap ≤30KB（API 24）；锁屏大图约 1000×1000、非 GIF
