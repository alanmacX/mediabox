# 实况窗权益申请 — 提交清单

> 提交入口：AGC → 增长 → 推送服务 → 配置 → 实况窗 →「申请开放能力/实况窗权益」
> （入口未开放则邮件 hwpush@huawei.com，主题【开通实况窗权益】-应用名称）

## 一、材料包（本目录）

| 文件 | 用途 |
| --- | --- |
| `业务场景说明-终稿.docx` | 申请必填材料①：详细业务场景说明（Word） |

## 二、提交前必须补齐的占位符（业务场景说明-终稿.docx）

- [ ] 【AGC 上架名称】（第 1 节 应用名称）
- [ ] 【测试包名 / 商用包名】（商用包名 com.mediabox.app；测试包名如有不同一并报备）
- [ ] 【Client ID】（AGC → 项目设置 → 常规 → 应用信息）
- [ ] 【个人 / 企业实名认证账号名称】（第 1 节 开发者主体）
- [ ] 【提交日期】

## 三、条件自检（对照官方要求）

- [x] 实名认证主体（个人/企业）
- [x] 仅中国大陆分发
- [x] 鸿蒙手机/平板（模拟器 API 24 / Phone 设备类型）
- [x] 场景匹配官方「进度（PROGRESS）」：用户主动发起、有时段、实时刷新、非营销
- [x] 端侧本地创建，不依赖推送服务（如后续要 Push 云侧创建再开通推送服务）
- [x] 单实况窗 ≤8 小时；每任务独立窗口、有明确结束事件
- [x] 设计符合《实况窗设计规范》：胶囊 1–3/1–6 字、卡片进度模板、百分比进度条
- [x] 不含隐私信息与营销内容

## 四、提交后流程

1. 等待权益开通（AGC 入口约 5 个工作日 / 邮件回复）。
2. 开通后在「实况窗 → 调测设备管理」按 Push Token 添加调试设备（≤100 台，24h 生效），
   之后可在真机上联调（demo 需接 Push Kit 获取 token，或先用模拟器继续演示）。
3. 正式权限申请需上架后月活 ≥1000 走快捷通道；不足则先用 60 天测试权益迭代。
