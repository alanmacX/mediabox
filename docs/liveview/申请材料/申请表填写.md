## 2. 场景描述（复制粘贴）

MediaBox（媒匣）是一款运行于 HarmonyOS 的本地媒体处理工具箱，提供视频转码、格式导出、GIF 转换、无损合并、音轨替换、字幕封装等本地媒体处理功能。用户在应用内选定媒体文件并主动点击「开始」后，处理任务通常持续数十秒至数十分钟，期间用户可能切出应用（返回桌面、锁屏）。希望通过实况窗，帮助用户在不打开应用的情况下实时查看媒体处理任务进度：任务开始时创建实况窗，状态栏胶囊展示「处理中 · 转码」，处理中展示百分比（如「45% · 转码中」），通知中心卡片通过进度可视化模板实时展示「已处理 x% · 预计剩余时间」，任务完成展示「完成 · 已保存」数秒后自动结束，任务失败或用户取消立即结束。每个任务对应独立实况窗，单一窗口生命周期不超过 8 小时；仅在用户主动发起时创建，展示内容仅为任务进度信息，不用于任何营销推广。采用端侧本地创建与更新（startLiveView / updateLiveView / stopLiveView，事件 PROGRESS），不依赖推送服务。
